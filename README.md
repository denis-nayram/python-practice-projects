# Python Practice Projects

A collection of beginner Python projects built while learning programming, file handling, and cybersecurity concepts.

These projects use sample data created for practice and demonstrate my progress in Python.

## Projects

### 1. Text File Analyser

A Python program that reads a text file and analyses its contents.

**Features**
- Counts lines and words.
- Searches for a user-selected word.
- Finds the longest word.

**Concepts practised:** File handling, strings, loops, functions, and lists.

[View Text File Analyser](./text-analyser/)

### 2. Phishing Message Analyser

A basic rule-based program that checks messages for potentially suspicious warning words.

**Features**
- Reads messages from a text file.
- Counts messages and searches for a chosen word.
- Flags messages containing configured warning words.
- Identifies the longest message.

**Concepts practised:** File handling, strings, loops, nested loops, conditionals, and functions.

**Important:** This is an educational exercise, not a real phishing detection system. Its results cannot prove that a message is safe or malicious.
