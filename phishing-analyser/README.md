# Phishing Message Analyser

A beginner Python project that checks text messages for potentially suspicious warning words.

## Features
- Reads messages from a text file
- Counts the number of messages
- Searches for a chosen word
- Flags messages containing warning words
- Reports the longest message

## Concepts Practised
- File handling
- Strings and string methods
- Lists
- Loops and nested loops
- Functions
- Conditional statements

## Important Note
This is an educational, rule-based exercise. It is not a real phishing detection system, and its results should not be treated as proof that a message is safe or malicious.
